# Tableau de Bord de Carrière - Amani Tlili 📊

Ce projet est un tableau de bord interactif développé en Python avec **Streamlit** et **Plotly**. Il sert de curriculum vitae dynamique, mettant en valeur mon parcours hybride en ingénierie logicielle et en analyse de données.

## 🛠️ Technologies Utilisées
* **Langage :** Python
* **Interface Web :** Streamlit
* **Visualisation de données :** Plotly (Gantt chart, Radar chart)
* **Manipulation de données :** Pandas

## 🚀 Comment exécuter le projet localement

1. Clonez ce dépôt :
   `git clone https://github.com/VOTRE_NOM_UTILISATEUR/cv-dashboard-amani.git`
2. Installez les dépendances :
   `pip install -r requirements.txt`
3. Lancez l'application :
   `streamlit run app.py`
